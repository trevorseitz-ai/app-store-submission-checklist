# App Store Submission Checklist

A standalone, interactive checklist for preparing Apple App Store and Google Play submissions.

## Use it

Download `app-store-submission-checklist.html` and open it in any modern browser. No installation, account, server, or internet connection is required.

The checklist includes:

- Apple, Google, and combined views
- 84 concise readiness checks
- Automatic completion totals
- Browser-saved progress
- App name, version, and target launch date
- A downloadable copy containing current progress
- Print and Save as PDF support
- One-click reset

## Publish with GitHub Pages

1. Upload `app-store-submission-checklist.html` and this `README.md` to the repository.
2. Rename `app-store-submission-checklist.html` to `index.html` if you want it to open at the repository's root Pages URL.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

## Privacy

Entered app details and checklist progress remain in the user's browser through local storage. The file does not transmit data to a server.

## Maintenance note

Apple and Google change submission requirements periodically. Review the checklist against current App Store Connect and Google Play Console guidance before relying on it for a launch.
